# 漢検トレーニング（3級）

漢検3級対策のスマホ向け学習ゲーム（単一HTML＋データJS）。画面上の名前は「漢検トレーニング」。英検トレーニング（naoaki-rmrb/junni-training）と同じ仕組み（1回10問・未学習→まちがえた→正解の順・タグ・ヒートマップ・きろく・アバター・世界遺産すごろく・ランキング）で作り、記録は英検とは別に保存する。

公開URL：https://naoaki-rmrb.github.io/kanken/

## 出題形式

| 形式 | 分野 | 答え方 |
|---|---|---|
| 手書き（筆順判定） | 書き取り・熟語の構成・漢字識別・四字熟語 | 画面のわくに指で1画ずつ書く。書き順がちがう画は受け付けない（形・位置のずれや逆向きの画はゆるめに受け付ける。同じ画で5回まちがえると自動で通す）。3回まちがえると次の画が光る（ヒント）。ヒントを使うと「ヒントで正解」（×あつかい） |
| 4択（書き取り） | 書き取り（4択） | 書き取りの問題を、同じ読み・似た形のひっかけ3つを入れた4択で答える（例：看病→完病・看秒・眼病）。答えたあと、ひっかけごとに理由（音が同じ・形が似ている）を表示。成績は手書きとは別に記録 |
| ひらがな入力 | 読み・送りがな | キーボードでひらがなを入力（カタカナで入れても可） |
| 記号をえらぶ | 部首・対義語・類義語・同音・同訓異字 | ボタンをタップ。ヒントでまちがいを1つずつ消せる（2回まで） |
| 誤字訂正 | 誤字訂正 | 文の中のまちがった漢字をタップし、正しい漢字を手書き |

## 問題について

- 問題文は日本漢字能力検定協会『漢検 ステージクリア 3級』による（`data/questions.js`、ページ番号つき）。
- 収録：ステージ1〜10（p.7〜106）とまとめテスト①②（p.108〜117）、計1,480問（書き取り4択435問を合わせ1,915問）。
- 正解は全問、別冊解答と照合済み。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（CSS・JS内蔵） |
| `data/questions.js` | 問題データ |
| `data/choices4.js` | 書き取り（4択）のひっかけ選択肢と理由（`tools/choice_candidates.py` で候補を集めて選んだもの） |
| `data/heritage.js`・`data/worldmap.js` | 世界遺産すごろく（英検トレーニングと同じ） |
| `strokes/<コードポイント16進>.json` | 書き順データ（常用漢字2,136字＋ひらがな・カタカナ） |
| `lib/hanzi-writer.min.js` | 手書きの判定（Hanzi Writer 3.7.3） |
| `gas/Code.gs` | ランキング用の Google Apps Script（漢検用。英検とは別のスプレッドシート） |
| `tools/build_strokes.py` | animCJK から `strokes/` を作るスクリプト |
| `stamp.sh` | 公開前に `APP_VER` を刻む（新しい版の通知用） |

## ランキングのセットアップ（最初の1回だけ）

1. Googleドライブで新しいスプレッドシートを作る（例：「漢検トレーニング ランキング」）。
2. 「拡張機能」→「Apps Script」を開き、`コード.gs` の中身を `gas/Code.gs` に置きかえて保存。
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行ユーザーは「自分」、アクセスできるユーザーは「全員（Anyone）」。
4. 出てきたURLを `index.html` の `const GAS_URL = "";` に入れる。
5. 2回目からの更新は「デプロイを管理」→ 鉛筆 →「New version」（「新しいデプロイ」はURLが変わるので使わない）。

## ライセンス・出典

- 書き順データ：[animCJK](https://github.com/parsimonhi/animCJK)（LGPL）。もとは [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)（Arphic Public License）。`licenses/animCJK/` を参照。日本の字形・筆順のデータ（例：「右」はノから、「左」は横画から）。
- 手書きの判定：[Hanzi Writer](https://github.com/chanind/hanzi-writer)（MIT）。`licenses/hanzi-writer/` を参照。
- 漢検の採点基準では筆順は『筆順指導の手びき』（文部省、1958年）による。アプリの判定は animCJK のデータによるため、まれに異なる字がありうる。
